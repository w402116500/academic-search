# 前端静态原型

这是用于确认视觉与流程方向的静态 HTML 原型，不连接 Vue、FastAPI 或真实模型服务。

当前方向是“输入驱动的研究画布”：用户先描述研究要求，再在同一页面中经历意图分析、方向确认、检索推进和候选文献就绪。冷白画布承载研究内容，钴蓝只标记当前动作和已完成的处理状态。

- `01-research-entry.html`：研究要求输入与连续任务推进原型
- `02-intent-confirm.html`：任务解析阶段和检索计划确认
- `03-literature-results.html`：文献筛选阶段、处理链路和候选检查器
- `04-research-workspace.html`：证据研究阶段的研究集合概览与索引状态
- `06-login.html`：登录原型
- `07-register.html`：注册原型
- `08-paper-detail.html`：候选文献详情、全文处理状态与可追溯的系统摘要
- `09-research-chat.html`：独立研究对话页，展示受证据约束的回答与引用定位。

登录后，首页右上角和研究对话侧栏通过工作区切换器直接进入各任务当前阶段，不再设置独立的工作区列表页。切换器默认展示最近使用的工作区，支持按名称或当前阶段搜索，结果区在自身容器滚动；正式接口将以关键词和游标分页按需加载。原型使用浏览器本地状态模拟登录，便于验证账号菜单与工作区切换，不连接真实认证服务。

提交首页要求时，真实系统会在后台创建工作区。原型使用定时事件模拟后台处理推送，因此不连接真实后端或模型服务。

原型中的“确认研究集合”会先要求二次确认，再演示解析、切块和索引完成后解锁研究对话。论文详情的加入动作只表示“待确认选择”；研究对话会写入用户的问题并展示检索执行状态，但不会伪造新的研究结论或引用。

可直接从 `01-research-entry.html` 打开并在页面间跳转。
