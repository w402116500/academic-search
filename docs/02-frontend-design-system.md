## 1. 设计定位：研究指挥台

产品不是在线期刊、论文阅读器或通用 SaaS 后台，而是一个帮助用户完成“提出研究问题 -> 获得候选文献 -> 核验全文 -> 基于证据研究”的专业工具。

前端采用 **深色控制层 + 浅色阅读层** 的研究指挥台风格：

- 深色区域承载全局导航、工作区切换、任务阶段、Agent 执行状态和高优先级操作，让用户感知系统正在处理一项可追溯的研究任务。
- 浅色区域承载文献表格、摘要、证据片段和引用内容，保证长时间阅读与复制时的可读性。
- 科技感来自信息结构、状态可视化、细线网格和精确的数据排版，而不是霓虹渐变、装饰光球或夸张动效。
- 工作区是数据与权限边界，但不是产品首屏。用户从自然语言研究问题进入，确认意图后才创建或进入工作区。

明确不用以下方向：

- E-Ink 纸感、杂志式大衬线和过度留白：它们适合阅读刊物，不适合高频筛选、核验与研究操作。
- 纯暗色长文阅读：会降低摘要、引用与证据片段的持续阅读体验。
- 通用后台的圆角卡片堆叠：会掩盖文献行之间可比较的数据差异。
- 赛博霓虹、玻璃拟态和大面积渐变：视觉噪声会削弱学术工具的可信度。

## 2. 视觉层级与配色

### 2.1 双层表面

| 层级 | 推荐色值 | 用途 |
|---|---|---|
| 控制层底色 | `#0B1020` | 顶部导航、工作区导航、任务进度区 |
| 控制层抬升面 | `#121A2A` | 深色层的弹出菜单、当前任务与状态条 |
| 阅读画布 | `#F5F7FA` | 文献结果、摘要、证据和设置页面背景 |
| 内容表面 | `#FFFFFF` | 表格详情、抽屉、输入控件和必要的浮层 |
| 主文字 | `#172033` | 正文、标题和数据 |
| 次要文字 | `#526174` | 辅助说明、时间与来源 |
| 结构描边 | `#D8E0EA` | 表格行、分区与控件边界 |

### 2.2 品牌色与语义色

品牌强调色采用青绿色，但在深浅表面分别使用满足对比度的色阶：

| 语义 | 色值 | 使用范围 |
|---|---|---|
| 主操作 / 已核验 | `#007C7A`（浅色层） / `#35D6CF`（深色层） | 开始研究、已核验、可用于 RAG、当前焦点 |
| 处理中 / 待核验 | `#B86E00` | 解析、下载、嵌入、需要用户确认 |
| 信息 / 可跳转 | `#2563EB` | DOI、官方入口、可展开的辅助信息 |
| 失败 / 不可用 | `#B42318` | 请求失败、全文不可用、入库阻断 |

颜色不能单独表达状态。每个状态同时显示文字、图标或形状标记，例如“已验证”“嵌入中”“不可入库”。

## 3. 字体与数据排版

界面统一使用无衬线字体，避免把操作界面做成期刊页面：

```text
界面标题与英文    IBM Plex Sans
中文界面与中文题名 Noto Sans SC
DOI、年份、状态与计数 IBM Plex Mono
```

- 标题应紧凑、信息化，不使用诗性的大字号文案。首屏标题可明确说明任务，例如“创建一项文献研究”。
- 论文标题允许两行截断；作者、年份、期刊、DOI 与处理状态保持单行对齐，便于快速横向比较。
- 摘要、推荐理由和证据正文限制在约 65-75 个字符行宽；表格列不受这一限制。
- 不用字距压缩来解决空间问题。窄屏时优先换行、隐藏次要列或打开详情面板。

## 4. 布局与组件原则

### 4.1 桌面优先的研究工作区

桌面端是核心：用户需要同时阅读文献、核验状态、查看证据与复制引用。默认工作区采用三类稳定区域：

```text
全局导航 / 任务状态（深色控制层）
├─ 左侧：研究工作区与流程导航
├─ 中间：当前任务的阅读或操作画布
└─ 右侧：上下文检查器（命中文献、字段详情、证据定位）
```

右侧检查器可按需收起；它展示可验证的处理轨迹、文献详情或证据定位，不展示模型内部思维链。

### 4.2 表格优先，详情按需展开

文献结果的主视图是可排序、可筛选的高密度表格，而不是一组高度不一的大卡片。每行至少稳定呈现：

```text
论文题名 | 作者与年份 | 来源 | 匹配度 | DOI 题录 | 全文 | RAG 状态 | 操作
```

- 点击行或“查看详情”打开右侧检查器，展示摘要、推荐理由、题录、证据范围和全文入口。
- 小屏将表格转换为紧凑的可展开行：保留题名、年份、状态与主要操作，其他字段进入详情抽屉。
- 卡片只用于独立、不可横向比较的对象，例如意图方向选择、失败说明和单条证据引用；禁止在卡片内再套卡片。

### 4.3 边框、圆角与密度

- 用 1px 描边、分区线和背景层级组织页面；阴影只用于菜单、抽屉和模态框。
- 圆角不大于 8px；表格行以固定高度和明确列宽保证状态变化不引发布局跳动。
- 常规页面使用 24px 左右的区块间距；操作型页面优先可扫描密度，不使用营销页式大留白。

## 5. 核心页面设计

### 5.1 研究入口：新建研究任务

首屏仍以自然语言多行输入框为唯一主操作，但它位于深色任务控制面中。页面同时以低优先级区域展示最近工作区和可用文献源状态，帮助用户继续研究，不抢占研究问题输入。

输入区必须说明用户可以描述对象、情境和想研究的关系；示例作为快捷填充，不作为营销内容。提交后进入意图确认，不直接展示工作区列表。

### 5.2 意图确认：研究任务解析台

系统把输入显式拆为研究对象、核心变量、关系或机制、情境、时间范围与语言范围。用户可确认、修改或补充条件；推荐检索方向可以用 2-3 个紧凑选择块呈现，但每个选择必须体现它会如何影响检索计划。

用户提交非空研究要求时先创建 `draft` 工作区并保存原始问题，再进入意图解析。解析完成后用户确认方向、时间范围和语言；确认后固化检索计划并启动多源检索。工作区名称来自用户问题的短标题，用户可在解析阶段修改。

### 5.3 检索进度：可验证的执行面板

检索过程以任务时间线和来源状态矩阵呈现：每个 provider 的请求、返回数量、失败原因、重试入口，以及元数据过滤、题录核验、全文获取等阶段均需可见。

进度展示的是可验证步骤和数量，不用“AI 正在思考”一类不可核验的文案。SSE 是首版的实时传输方式。

### 5.4 文献结果：研究数据表

结果页顶部显示当前研究问题、已完成与失败的数据源、筛选条件、总数量和排序策略。中部是文献结果表；右侧检查器承载单篇文献详情。

表格状态必须清楚区分：

- `题录已核验`：可复制标准引用。
- `全文待获取` 或 `全文不可用`：可查看和复制题录，但不可加入研究集合。
- `全文已验证`：可执行入库。
- `解析 / 切块 / 嵌入中`：已进入研究集合，尚不可问答。
- `RAG 就绪`：已完成可检索索引。

### 5.5 RAG 研究工作区：证据分析台

研究工作区的中心不是聊天气泡，而是带引用编号的研究回答与证据。左侧列出研究集合、文献处理状态和流程入口；中间显示回答、结论边界与证据引用；右侧检查器显示命中文献、页码、段落、检索阶段和原文定位。

用户必须能够从任何结论跳到对应原文片段。证据不足时，中心区域显示证据缺口和下一步操作，而非生成看似完整的答案。

## 6. 交互与动效

- 默认过渡时长为 150-200ms，只用于颜色、透明度、边框和抽屉位移，不让动效改变布局尺寸。
- 处理中的行、任务节点和状态徽标使用克制的进度反馈；必须响应 `prefers-reduced-motion`。
- 图标采用 Lucide Vue。图标按钮必须提供可见提示或 `aria-label`，重要命令使用图标加文字。
- Toast 只用于复制成功等短暂确认；网络失败、全文不可用和部分数据源失败必须保留在页面中，支持重试或查看原因。

## 7. 技术实现约束

| 层 | 选择 | 作用 |
|---|---|---|
| 框架 | Vue 3 + TypeScript | 页面、组合式逻辑与类型边界 |
| 样式 | Tailwind CSS | 以设计令牌实现深浅双层主题和响应式布局 |
| 组件 | Reka UI + shadcn-vue | 提供无障碍基础，由项目样式系统统一外观 |
| 图标 | Lucide Vue | 统一操作和状态图标 |
| 服务端状态 | `@tanstack/vue-query` | 检索、文献、工作区和重试的缓存语义 |
| 客户端状态 | Pinia | 研究问题草稿、当前表格视图、检查器开关等本地状态 |
| 实时 | SSE | 推送检索与文献处理进度 |
| 构建 | Vite | 前端开发与构建 |

硬约束：

```text
单文件不超过 300 行
按 components / views / composables / stores / lib 分层
z-index 仅允许 10 / 20 / 30 / 50 四档
所有可点击元素具备可见焦点和 cursor-pointer
断点覆盖 375 / 768 / 1024 / 1440
响应 prefers-reduced-motion
```

## 8. 交付前检查清单

- [ ] 深色控制层与浅色阅读层职责明确，长文阅读不在纯暗色背景上进行。
- [ ] 无纸张纹理、大衬线标题、装饰渐变或发光背景。
- [ ] 结果主视图为可排序表格，列宽、行高和状态标记稳定。
- [ ] 详情、证据和原文定位进入检查器或抽屉，不把表格行膨胀成卡片墙。
- [ ] 相关性、质量、全文和 RAG 状态同时使用文字与非颜色标记。
- [ ] 引用内容的出处标注无法被复制剥离，复制题录有成功反馈。
- [ ] 单源失败、全文不可用和证据不足均明确说明原因和下一步。
- [ ] 375 / 768 / 1024 / 1440 下无横向溢出；移动端可查看结果和证据。
- [ ] 键盘焦点、对比度、表单标签、图标无障碍标签均通过检查。
