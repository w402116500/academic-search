# 研究范围文献详情

## Goal

在研究问答页内展示当前工作区研究范围中的文献详情，让用户不必离开证据研究即可核对来源。

## Requirements

- 入口位于研究聊天头部的“研究范围”，桌面与窄屏均可点击；点击后在当前页面打开可关闭的范围面板，不跳转到集合页面。
- 面板展示当前工作区文献列表；点击文献后显示标题、作者、期刊/会议、年份、DOI、正式引用、来源链接和入库状态。
- 复用已有工作区文献查询及 OpenAPI DTO，不新增重复的详情 API 或前端 wire type。
- 对缺失的可选元数据给出克制的空状态，不伪造内容；来源链接仅在存在时开放新窗口。
- 支持加载、请求失败、无文献和窄屏状态；关闭详情或范围面板后当前会话与正在运行的研究不受影响。
- 研究入口同时展示用户自己的待完成删除工作区，作为不可写工作区的恢复入口；该区域不与研究范围文献清单混淆。
- 不实现内置 PDF 阅读、摘要阅读或证据块跳转。

## Acceptance Criteria

- [ ] 在研究聊天中，用户能在任意视口打开研究范围并选择任一已入库文献查看全部约定元数据。
- [ ] 文献条目与详情数据均来自 `CollectionDocumentsResponse`，不额外请求未定义接口。
- [ ] 详情面板在桌面和窄屏下可访问、可关闭，文本与控件不溢出或遮挡。
- [ ] 没有文献、加载中或加载失败时，用户得到明确状态且研究问答功能保持可用。
- [ ] 新增的前端测试覆盖文献选择/关闭与关键展示契约，并经真实浏览器检查。
- [ ] 研究入口的待完成删除区域可继续删除，但不渲染为可研究的工作区。

## Notes

- 依赖父任务的产品范围确认；可独立验证和交付。
